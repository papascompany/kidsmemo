# 연차유급휴가 운영 기준

이 문서는 키즈메모 연차 계산 기능이 참고하는 법정 최소 기준을 정리한 것입니다. 개별 취업규칙, 단체협약, 휴직·출산·육아 관련 출근 간주 기간, 사용자 귀책 여부에 따라 실제 정산이 달라질 수 있으므로 최종 노무 판단을 대신하지 않습니다.

## 적용 전제

- 상시근로자 5인 이상 사업장
- 4주 평균 1주 소정근로시간 15시간 이상인 근로자
- 법정 기준보다 유리한 취업규칙·단체협약이 있으면 유리한 기준을 확인

## 법정 계산 규칙

- 1년 미만: 1개월 개근 시 1일, 최대 11일
- 1년 이상: 직전 1년 출근율이 80% 이상이면 15일
- 1년 이상이고 출근율이 80% 미만이면 월별 개근 기준을 확인
- 3년 이상: 최초 1년을 초과하는 계속근로연수 매 2년마다 1일 가산
- 가산분을 포함한 총 한도는 25일
- 1년을 마친 뒤 근로관계가 유지되는 시점과 퇴직일을 구분

기능은 입사일 기준을 기본으로 계산합니다. 기관이 회계연도 기준을 운영하는 경우에도 입사일 기준보다 불리하지 않아야 하며, 퇴직 시 부족분을 비교·정산해야 합니다. 이 비교는 단순히 매년 1월 1일에 15일을 부여하는 것으로 대체하지 않습니다.

## 기능의 입력 원칙

- 출근율 또는 월별 개근 자료가 없으면 임의로 연차를 부여하지 않고 `자료 필요` 경고를 표시합니다.
- 사용일수는 `annual_leave_grants` 원장에 기록된 사용분을 기준으로 잔여일수를 계산합니다.
- 직원 원아 출석은 기존 `attendance_records`를 사용하지 않습니다. 직원 고용정보와 휴가 신청은 별도 테이블로 분리합니다.
